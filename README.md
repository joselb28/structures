# CarNBus (transit_app)

Simulation multi-agents de transport urbain (bus + Uber) — projet de structures de données, Java 21 / Swing.

## Démarrer

Dans IntelliJ : ouvrez `src/main/java/com/transit/Main.java` et cliquez sur ▶ à côté de `main`.
Une fenêtre vous fait choisir un scénario.

Avec Maven :

```bash
mvn compile exec:java
```

```bash
mvn test
```
